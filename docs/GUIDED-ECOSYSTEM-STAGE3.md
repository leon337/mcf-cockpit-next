# Etapa 3 — Guided Ecosystem View

## Objetivo

Melhorar a compreensão do ecossistema sem alterar sua fonte de verdade.

A hierarquia canônica continua vindo de:
- Project Registry do MCF;
- Current State do MCF;
- GitHub REST API para metadados públicos.

A Etapa 3 muda apenas a forma como esses dados são apresentados.

## Visões

### Entender o ecossistema

Visão padrão.

Fluxo de leitura:

1. LEANDRO decide.
2. MCF coordena.
3. As áreas especializam responsabilidades.
4. Os projetos executam funções concretas.

Cada grupo responde primeiro a uma pergunta simples:

- Fundação — mantém o MCF de pé.
- Execução e inteligência — faz o trabalho acontecer.
- Memória e continuidade — ajuda o sistema a lembrar.
- Produtos e casos — onde o MCF vira solução real.
- Laboratórios — onde testamos e medimos.
- Interfaces e observabilidade — onde o sistema é visto e acompanhado.
- Ferramentas de suporte — ajudam outras partes a funcionar.

Os projetos ficam recolhidos por padrão e aparecem por expansão progressiva.

### Todos os repositórios

Mantém o inventário pesquisável.

## Níveis de confiança traduzidos

- Oficial — presente no Project Registry.
- Integrado — relação estrutural documentada.
- Referenciado — citado pelo MCF, sem registro próprio.
- Descoberto — relacionado pelo GitHub, ainda não canônico.

## Princípio

A visão simples nunca altera o significado técnico. Ela traduz os mesmos dados para uma leitura progressiva.
