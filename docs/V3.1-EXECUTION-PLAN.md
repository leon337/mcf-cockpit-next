# MCF Cockpit Next — V3.1 Execution Plan

Mission: MCF-COCKPIT-V3-1-001
MCF Issue: #296
Baseline: e781a71d3a6e084f5ecbcb2da773fadec94846f3
Risk class: B

## Goal

Evoluir a V3 para uma experiência read-only mais operacional, compartilhável e recuperável, mantendo stack, proveniência e privacy boundary.

## Invariants

- no fabricated data;
- no inferred private metadata;
- no fabricated progress;
- no undocumented dependency claims;
- no framework replacement;
- no Execution Plane;
- no external write actions;
- public GitHub remains secondary action where applicable.

## Workstreams

### WS-A — Navigation State

- canonical URL state for view/area/project/tab/mission/filter;
- reload reconstruction;
- browser back/forward via popstate;
- project/tab selection reflected in URL;
- deep links remain backward compatible.

### WS-B — Search + Mission Detail

- make search semantics explicit per view;
- ensure visible search effect;
- add read-only Mission Detail using public issue fields already allowed by mission data boundary;
- keep external GitHub link as secondary action.

### WS-C — Insights + Graph Operability

- project chips in Insights become navigable;
- add graph focus/filter controls using existing evidence categories/groups;
- do not create dependency edges without source evidence;
- rename provenance semantics to avoid quality-score interpretation.

### WS-D — QA / Regression

- TypeScript strict;
- production build;
- API syntax;
- git diff --check;
- privacy/no-fabrication regression;
- keyboard behavior;
- mobile/768/1440/1920 layout;
- URL reload/back-forward cases;
- V3 baseline regression.

## Integration order

1. state contract and URL helpers;
2. project/tab deep links;
3. search semantics;
4. Mission Detail;
5. Insights navigation;
6. graph focus/filters;
7. terminology;
8. regression/audit.

## Acceptance

- relevant navigation state is shareable by URL;
- reload reconstructs the expected state;
- back/forward works across Cockpit navigation;
- global search never appears inert without explanation;
- a mission can be understood inside the Cockpit without inferred progress;
- Insights can open affected projects;
- graph filtering preserves provenance;
- private-project boundary remains intact;
- no V4 capability is introduced.

## Release boundary

Implementation and review may proceed on this branch.
Merge is an internal reversible gate after evidence.
Public deployment remains a separate release/audit action.
